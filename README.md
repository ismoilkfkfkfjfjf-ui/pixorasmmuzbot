# 🚀 Pixora SMM Bot

Professional Telegram SMM xizmatlari, Virtual raqamlar do'koni va zamonaviy **Telegram Mini App (Web App)** boti.

## ✨ Imkoniyatlari

1. **⚡ SMM Xizmatlari (SeenSMS API Integratsiyasi):**
   - ✈️ **Telegram**: Obunachilar (aralash / toza o'zbek), post ko'rishlar, ijobiy reaksiyalar
   - 📸 **Instagram**: Obunachilar, layklar, video/reels ko'rishlar
   - 🎵 **TikTok**: Obunachilar, layklar, video ko'rishlar
   - 🎬 **YouTube**: Obunachilar, layklar, yuqori sifatli ko'rishlar
   - Buyurtmalar avtomatik qabul qilinadi va real vaqt rejimida yuritiladi.

2. **📲 Virtual Raqamlar (SMS qabul qilish):**
   - Telegram, WhatsApp, Instagram, TikTok, Google va boshqalar uchun virtual raqam olish.
   - SMS kodi kelganda bot darhol foydalanuvchiga ovozli xabar bilan yetkazadi.
   - Agar kod kelmasa, "Bekor qilish" tugmasi orqali to'langan pul to'liq hisobga qaytariladi.

3. **📱 Telegram Mini App (Web App):**
   - Cyberpunk glassmorphism dizayni
   - Real vaqtda narx hisoblagich (kalkulyator)
   - Filtrlar va qidiruv tizimi
   - Buyurtmalar tarixi va faol raqamlarni kuzatish

4. **📥 Bio & Profil Rasm (Avatar HD) Yuklovchi:**
   - Istalgan Instagram yoki Telegram profilining HD rasmi va bio ma'lumotlarini yuklab beradi.

5. **👥 Referal va Bonus Tizimi:**
   - Har bir taklif qilingan do'st uchun hisobga 500 so'm bonus beriladi.
   - Shaxsiy referal havola va daromad statistikasi.

6. **👑 To'liq Admin Paneli (`/admin`):**
   - Bosh administrator ID: `8422157752`
   - Real vaqt statistikasi
   - SeenSMS API kalitini kiritish va almashtirish
   - SeenSMS API hisob balansini ko'rish

   - Foydalanuvchilarga xabar tarqatish (Broadcast)
